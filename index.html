Welcome

This is a starter template for static HTML, CSS, and JavaScript websites.

It provides clean foundational styling, built-in light/dark theme switching, and modular structure without requiring any build steps or frameworks.

Core Principles

The architecture emphasizes semantic HTML, responsive CSS with modern custom properties, and progressive enhancement through vanilla JavaScript.
